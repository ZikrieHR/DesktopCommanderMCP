## 2025-05-18 - Native indexOf vs JS Character Loop for Newline Operations
**Learning:** In V8 / Node.js, string indexing loops like `for (let i=0; i<str.length; i++) str[i]` create single-character string allocations on every iteration and run JS bytecode overhead. Replacing manual loops with native `indexOf('\r')` and `indexOf('\n')` leverages optimized C++ routines, yielding up to 27x faster detection and 8x faster counting.
**Action:** When inspecting or scanning string line endings or single-character patterns in node/TS utilities, use native `indexOf` / `includes` fast paths before falling back to manual loops.
